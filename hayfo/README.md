# هايفو — متجر إلكتروني تجريبي

واجهة متجر عربية باتجاه RTL تضم ثلاثة أجهزة للمساج والتدليك: جهاز BBK متعدد الوظائف بـ228 درهماً، وجهاز مساج الرقبة Shiatsu بـ299 درهماً، وجهاز مساج الوجه EMS ميني بسعر عند الطلب. السلة تحفظ المنتجات المسعّرة محلياً في المتصفح، ونموذج الطلب تجريبي.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث، أو استخدم خادماً محلياً ثابتاً من هذا المجلد، مثلاً:

```powershell
py -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## ملاحظات

- لا يوجد خادم خلفي أو نظام دفع أو حفظ للطلبات؛ إتمام الطلب والاشتراك في النشرة يعرضان تجربة واجهة فقط.
- الرسوم التوضيحية للمنتجات بديل مؤقت عن صور المورد. روابط Alibaba تفتح صفحة المورد؛ يجب مراجعة المواصفات والأسعار قبل الإطلاق.
- الصور والخطوط تُحمّل من Unsplash وGoogle Fonts عند توفر الإنترنت.
